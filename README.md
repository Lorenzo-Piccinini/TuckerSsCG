This software package includes the subspace gradient descent methods for linear tensor equations developed and analysed in the manuscript

Iannacito, Martina, Lorenzo Piccinini, and Valeria Simoncini. "Subspace gradient descent method for linear tensor equations." arXiv preprint arXiv:2602.21974 (2026). https://arxiv.org/abs/2602.21974 

This software is intended to reproduce some the numerical experiments illustrated in the manuscript mentioned above.

Please, acknowledge our work by citing our manuscript whenever you use the software provided here in your research.

### Prerequisites

The software has been developed by using Matlab, version 2025b. The software requires the following toolboxes: the Oseledets TT-Toolbox (https://github.com/oseledets/TT-Toolbox), the SSCG software (https://github.com/palittaUniBO/sscg/), and htucker toolbox (https://www.epfl.ch/labs/anchp/index-html/software/htucker/).
